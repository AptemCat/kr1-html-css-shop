# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `sitemap.xml` — карта опубликованных страниц сайта;
- `css/style.css` — файл стилей;
- `js/main.js` — логика модального окна и обработки формы;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — раздел страницы;
- `page-layout` — раскладка главной страницы;
- `aside-info` — боковой информационный блок;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `catalog-products` — список товаров в каталоге;
- `filters-form` — форма фильтров;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `success-message` — сообщение об успешной отправке;
- `button` — кнопка;
- `site-footer` — подвал сайта.

При аудите заменены `site-logo` на `site-header__logo`, `main-content` на `page-layout__content`, `form-field` на `order-form__field` и `form-actions` на `order-form__actions`. Селекторы по вложенным тегам заменены прямыми классами элементов, например `product-card__title`, `site-nav__link` и `filters-form__input`.

Модификаторы задают варианты компонентов: `site-nav__link--active` выделяет текущую страницу, `product-card--featured` — первую карточку, `button--primary` и `button--secondary` — основную и второстепенную кнопки. Модификатор всегда используется вместе с базовым классом. Атрибуты `id` сохранены для якорных ссылок и JavaScript; для стилизации они не используются.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке;
- трёхколоночная сетка товаров на CSS Grid;
- Flexbox для шапки, навигации и кнопок формы;
- закреплённая шапка на `position: sticky` с `z-index`;
- единая навигация между главной страницей, каталогом и контактами;
- якорные ссылки на разделы главной страницы;
- хлебные крошки на внутренних страницах;
- форма фильтров по категории и цене в каталоге;
- Grid-раскладка каталога с боковой областью фильтров.
